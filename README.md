# Lan Page - Laravel v12


## Installation

1. **Clone the repository**

   ```bash
   git clone <repo-url>
   cd lan-page-v2


2. **Setup environment (copy & adjust .env file)**
   ```bash
   cp .env.example .env

   ```
3. **install dependencies**
   ```bash
   composer install

   ```
4. **build assets**
   ```bash
   npm install && npm run build

   ```
5. **run migrations**
   ```bash
   php artisan migrate

   ```
6. **generate app key**
   ```bash
   php artisan key:generate

   ```

7. **generate storage link**
   ```bash
   php artisan storage:link

   ```
